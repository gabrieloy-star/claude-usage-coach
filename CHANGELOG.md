# Changelog

## 1.2.0

First public version.

- The strip above the prompt: a question Claude is waiting on, context, prompt cache and Claude's steps, with four buttons: ⇲ compact, ⓘ insights, ☰ details and ✦ status.
- Short hover cards that end with what to do.
- The side pane with three views: Session, Project and All projects.
- Buttons to clear old sessions, merged worktrees and old Xcode builds, and to shut down a simulator. Each asks first and moves files to the Trash.
- Idle compact, 5 minutes before the 1-hour prompt cache expires, and what each compaction saved.
